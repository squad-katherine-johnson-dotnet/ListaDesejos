# 🛍️ Lista de Desejos

Projeto desenvolvido em squad como parte do desafio de **Angular**.

## 🎯 Objetivo

Desenvolver uma aplicação de lista de desejos utilizando Angular, aplicando os conceitos estudados durante o módulo, como componentes, data binding, serviços, consumo de API, rotas e formulários com validação.

O desafio também tem como objetivo praticar a **divisão de tarefas, integração do código e desenvolvimento em equipe**.

## 📌 Funcionalidades

A aplicação permitirá:

- Listar produtos da API;
- Visualizar informações dos produtos;
- Adicionar produtos à lista de desejos;
- Remover produtos da lista de desejos;
- Adicionar itens manualmente à wishlist;
- Definir prioridade para os itens adicionados:
  - Baixa;
  - Média;
  - Alta;
- Validar o formulário de cadastro dos itens.

## 🛠️ Tecnologias

- Angular
- TypeScript
- HTML
- CSS
- Fake Store API
